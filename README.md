# Millennium Snake

Duel Monsters / Ancient Egypt inspired Snake. React + TypeScript + Vite, Canvas engine, PWA, Capacitor (Android).

## Run
```
npm install
npm run dev        # http://localhost:5173 (also on LAN for phone testing)
npm test           # engine unit tests
npm run build      # typecheck + production build (+ service worker)
```

## Controls
- **Phone:** touch and drag anywhere on screen; keep dragging to keep turning. Optional on-screen D-pad in Settings.
- **Laptop:** arrow keys or WASD. Space/Esc/P pauses, E uses Spirit Form.

## Replacing artwork
Drop files in `src/assets/` – no code changes:
- `sprites/{puzzle,monsterCard,godCard,millenniumEye,obstacle,head}.png` (head faces right)
- `characters/menu-dragon.png|webp` (menu / game-over hero)
New collectibles: add an entry in `src/game/engine/config.ts` + a sprite.

## Android (Capacitor)
The `android/` project is already generated. Requires Android Studio (JDK 17+, Android SDK).
```
npm run cap:android   # build web, sync, open Android Studio
npm run cap:run       # build, sync, run on a connected device/emulator
```
Release: Android Studio > Build > Generate Signed Bundle / APK (AAB for Play Store).
After changing web code always `npm run build && npx cap sync android`.
App id: `com.millenniumsnake.game` (change in `capacitor.config.ts`). Launcher icons (PWA + Android adaptive) are generated by `npm run icons` (scripts/make_icons.py).

## PWA
`public/manifest.webmanifest` + `public/sw.js` (production build only). Android Chrome: menu > Install app. iOS Safari: Share > Add to Home Screen.
